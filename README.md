# A Big-Data Pipeline and Explainable Graph Neural Network for Credit Risk Assessment in Uganda's Fintech

## Project Overview

This research investigates how Graph Neural Networks (GNNs) can support credit-risk assessment by combining borrower characteristics with relational information.

The study focuses on the potential application of graph-based credit scoring in Uganda's fintech sector, particularly for borrowers with limited traditional credit histories.

## Research Objectives

1. Develop a data-processing pipeline for preparing credit-risk data.
2. Compare a traditional machine learning baseline with a Graph Neural Network.
3. Investigate whether observed relational information improves default prediction.
4. Apply explainability techniques to understand model predictions.
5. Discuss the opportunities and limitations of applying the approach in Uganda's fintech environment.

## Proposed Methodology

- **Baseline model:** Logistic Regression
- **Graph model:** GraphSAGE
- **Explainability:** SHAP and GNNExplainer
- **Evaluation:** ROC-AUC, precision, recall, F1-score and other appropriate metrics

## Current Progress

## Dataset Considerations

The Nigerian loan dataset is being used provisionally to develop and evaluate the data-processing pipeline and baseline model.

Its referral network is sparse and is not currently considered sufficient for the primary graph-learning experiment.
